# CareerOS Product 1 v1.05 release qualification

Status: **released as package version 1.0.5 and annotated tag v1.0.5**.

## Scope

This release added the local Career Profile workflow: bounded text extraction
from supported PDF/DOCX inputs, deterministic Career Fact candidates with exact
evidence, deliberate human review, and immutable Career Profile snapshots.
Private résumé Materials and profile state remain local. OCR/image-only PDF,
legacy DOC, arbitrary layout reconstruction, hosted extraction, submission,
outreach, and cloud synchronization are outside this release.

## Qualification boundary

The release retained schema 13, added no dependency, and preserved the stable
`careeros` namespace. Qualification covered focused and full regression tests,
strict static checks, browser acceptance, installed-package smoke, and the
supported v1.0.0-to-v1.0.5 migration/recovery path using disposable private
state. Complete recovery requires the database, matching Materials root, and
applicable private configuration/profile state.
