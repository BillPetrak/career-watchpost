# Career WatchPost v1.2.2 release qualification

Status: **PASS / CLOSED — qualified, owner accepted, and released as a
source-only repository**.

## Scope

Career WatchPost v1.2.2 applies the public product identity and portfolio
presentation to the accepted CareerOS Product 1 behavior. The stable
`careeros` distribution/import namespace, CLI commands, environment variables,
XDG paths, API routes/contracts/headers, schema 14, persistence identifiers,
collectors, ranking behavior, and four systemd units remain unchanged. It adds
no product feature, hosted service, provider credential, migration, or release
version beyond `1.2.2`.

The public Git history is derived from the genuine private development history
with privacy and presentation sanitization. The original sequence and
timestamps are preserved; excluded research, private operational evidence, and
private identity metadata are not public release content. This sanitization
does not claim new engineering accomplishments.

## Qualification authority

The accepted Product 1 v1.2.1 full regression remains the behavioral baseline:
**4,208 tests passed with zero failures and two accepted warnings**. The
v1.2.2 presentation-focused qualification passed **567 tests with zero
failures and one accepted warning**, plus Ruff, formatting, strict mypy,
JavaScript syntax, Git whitespace, installed-package, browser, asset, and
privacy checks. Five portfolio screenshots were created with fictional
disposable data and contain no textual metadata or private/provider data.

Neither the 4,208-test v1.2.1 suite nor the 567-test v1.2.2 suite was rerun
solely for public-history sanitization. The sanitization qualification instead
uses complete historical mapping, object/privacy scanning, exact functional
invariance checks, AST-equivalent docstring verification, focused employer
identity/policy tests, relevant static checks, and public-documentation/link
consistency checks.

## Source-only publication

This repository is the source-only publication authority: it contains source
code, documentation, the sanitized history, and the seven annotated tags. No
wheel or source distribution was rebuilt under version 1.2.2, and none forms
part of this release. Installation therefore starts from a source checkout as
documented in `docs/user-guide.md`.

The MIT license covers repository source, not provider job descriptions,
payloads, logos, trademarks, or employer content. Provider-specific credit,
linking, collection, storage, and redistribution conditions remain applicable;
public endpoint availability is not a general redistribution licence.

## Current limitations

OCR/image-only PDF, legacy DOC, and arbitrary multiline/column PDF geometry
reconstruction remain unsupported. Career Profile and ranking profile remain
separate authorities. Model-assisted résumé extraction, hosted deployment,
public live-data demonstrations, and automatic application submission remain
out of scope.
