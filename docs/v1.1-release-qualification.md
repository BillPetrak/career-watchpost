# CareerOS Product 1 v1.1 release qualification

Status: **released as package version 1.1.0 and annotated tag v1.1.0**.

## Scope

Product 1 v1.1 retained the seven built-in sources and added owner-configured,
credential-free Lever, Greenhouse, Workable, and SmartRecruiters collectors.
Private `sources.yaml` selection remained fail-closed and outside packages.
The collectors use bounded public read endpoints and do not submit
applications, discover accounts, or use provider credentials.

## Qualification evidence

Schema 13 and all third-party dependency versions were unchanged. Ruff,
formatting, strict mypy, Git whitespace checks, installed-package smoke, and an
authoritative full suite passed. The full result was **3,889 passed, zero
failures, two accepted warnings**. Qualification used disposable XDG/runtime
state and made no live provider request.
