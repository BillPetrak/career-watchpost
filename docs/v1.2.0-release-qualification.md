# CareerOS Product 1 v1.2.0 release qualification

Status: **released as package version 1.2.0 and annotated tag v1.2.0**.

## Scope

This release introduced schema 14 and the supported schema-13-to-schema-14
migration after backup. Today Review-ranking authority became durable through
persisted generations, items, and current bindings, with an asynchronous local
worker and an explicit administrative rebuild command. Unready, stale, or
corrupt ranking fails closed with the documented HTTP 503 contract.

## Qualification evidence

The corrected authoritative full suite passed **4,013 tests with zero failures
and two accepted warnings**. Static checks, focused schema/release tests,
installed-package smoke, semantic ranking checks, persistence/privacy checks,
and independent review passed in isolated disposable state. No third-party
dependency, provider behavior, or provider registry changed.
